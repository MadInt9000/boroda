# Правила для агентов

## Плоские проверки вместо лестниц `if let`

Где это возможно, избегайте вложенных конструкций вида `if let` / `if`. Используйте
ранние выходы из блока:

- внутри циклов — `continue` и `break`;
- внутри функций — `return`;
- для разбора `Option`/`Result` — `let ... else { ... };`.

Вместо проверки, которая может не дать значения, предпочитайте присваивание
с безопасным значением по умолчанию, например:

```rust
let entries = std::fs::read_dir(".")
    .map(|entries| entries.flatten().collect::<Vec<_>>())
    .unwrap_or_default();

for entry in entries {
    let Ok(file_type) = entry.file_type() else {
        continue;
    };
    if !file_type.is_file() {
        continue;
    }

    // ...
}
```

Такой стиль применяйте везде, где он не ухудшает читаемость: в загрузчиках,
парсерах, обработчиках событий и других местах с несколькими последовательными
проверками.
